# Entry D checkpoints

All ten files are included in Git. The [manifest](manifest.json) records their order and individual SHA-256 hashes. The first three are ordinary seeds, the next three use control-physics features, the next three use short-spell sampling, and the last has hidden width 256. All contribute one tenth of the arithmetic mean. Training inputs, random seeds and hyperparameters are in [recipe.json](../lyari/jobs/recipe.json).
